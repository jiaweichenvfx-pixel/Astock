# 「看长做短」个人量化投研决策系统 V5.1 —— 最终定稿 Spec

> 状态：已定稿（2026-08-29 头脑风暴拍板后）
> 技术栈：Python 3.13 + FastAPI + 单文件网页前端（本地运行）
> 数据源：akshare（封装 adapter，失败降级本地缓存）
> 定位：只输出「建议指令」，绝不连接券商、绝不自动下单。

---

## 0. 全局口径（锁定）

1. **比例分母统一 = 总资产（净资产 + 融资余额）**
   - 融资比例 = 融资余额 / 总资产
   - 总仓位 = 持仓市值 / 总资产
   - 单只仓位 = 单只市值 / 总资产
   - 现金储备 = 现金 / 总资产
   - 净资产 = 总资产 − 融资余额（仅用于展示）
   - 总资产 = Σ持仓市值 + 现金

2. **评分区间边界**：左闭右开。`<30` 急救；`[30,50)` 防守；`[50,70)` 平衡；`>=70` 进攻。

3. **系统只出建议，不自动交易**：spec 中的「市价单/限价单」= 建议挂单方式。UI 强制展示免责声明。

## 1. 账户健康度评分卡（模块1，总开关）

总分 100，决定运行模式。

| 维度 | 满分 | 规则（左闭右开） |
|---|---|---|
| 融资比例 | 25 | <30%→25；[30,50)→15；[50,70)→5；≥70→0 |
| 浮亏幅度（账户整体） | 25 | 浮盈>10%→25；浮亏[0,10)→15；[10,20)→8；≥20→0 |
| 持仓质量 | 25 | 基础25分，按持仓颜色扣分：🟢−0 / 🟡−5 / 🟠−10 / 🔴−15（扣到0止） |
| 持仓集中度 | 15 | 3–5只→15；6–8只→10；>8只→5（不足3只按5分，含空仓边界） |
| 市场环境 | 10 | 环境分0-10 直接映射：火热≥8→10，温和[4,8)→7，寒冷<4→3 |

**持仓颜色（二维健康度 = 浮亏程度 × 质量评级）**：

| 颜色 | 判定 |
|---|---|
| 🟢 | 评级=卓越/合格 且 浮亏 > −5% |
| 🟡 | 评级=预警，或 合格/卓越但浮亏 [−15%,−5%) |
| 🟠 | 浮亏 [−25%,−15%)，或触发时间止损/技术卖点 |
| 🔴 | 评级=黑名单 / 浮亏 < −25% / 触发硬止损或基本面止损 |

**模式判定**：🔴急救(<30) / 🟠防守(30-50) / 🟡平衡(50-70) / 🟢进攻(≥70)。

## 2. 仓位管理引擎（模块2，强制风控）

| 模式 | 单只上限 | 总仓位上限 | 融资上限 | 现金储备 |
|---|---|---|---|---|
| 🔴急救 | 5% | 60% | 0% | 40% |
| 🟠防守 | 10% | 70% | 20% | 30% |
| 🟡平衡 | 20% | 85% | 40% | 15% |
| 🟢进攻 | 30% | 100% | 60% | 0% |

- 任何买入必须先过仓位门控：总仓位超上限、单只超上限、融资超上限，任一超限 → 禁买，提示「请先减仓」。
- 超上限时，除禁买外，主动产出「减仓到目标」指令，联动卖出处理器。

**分步降杠杆路径（新增，锁定）**：从当前仓位到目标仓位分 3 步，每步给出目标总仓位/融资/现金 + 时间窗口 + 触发条件（如「反弹到 X 元就卖，不追低」），避免割在最低点。生成规则见 `app/engine/position.py`。

## 3. 卖出优先处理器（模块3，最终防线）

### 3.1 四大机制

| 机制 | 触发条件 | 建议挂单 | 优先级 |
|---|---|---|---|
| 硬止损 | 价格跌破止损线 | 市价 | 🔴最高 |
| 基本面止损 | 季报恶化 / ST / ROE 下滑 / 评级降级 | 市价 | 🔴最高 |
| 时间止损 | 持仓N天未创新高且收益<阈值 | 限价 | 🟠次高 |
| 技术卖点 | 顶背离 / 超买 / 放量滞涨 | 限价 | 🟡中等 |

**止损口径（锁定）**：
- **新买入**：固定百分比，止损价 = 买入价 × (1 + 止损%)。急救−3 / 防守−5 / 平衡−7 / 进攻−10。
- **已深套持仓**（浮亏已超该模式止损线）：不机械割肉，改由「时间止损 + 基本面止损 + 反弹减仓」主导；止损/减仓价 = 关键支撑位或反弹卖点。

**时间止损定义（锁定）**：持仓 ≥ N 天后，若「未创新高 且 区间收益 < X%」→ 触发。N 与 X 由模式驱动。

**基本面止损字段（锁定）**：扣非净利润同比增速、ROE(TTM)、是否 ST、审计意见。季度更新。

**技术卖点量化（锁定）**：顶背离（价创新高 MACD 不创新高）、RSI 超买 >80、放量滞涨（量 >1.5×均量 且 涨幅 <2%）。

### 3.2 紧急度打分

- 基础分：硬止损 80 / 基本面止损 75 / 时间止损 65 / 技术卖点 45–60（顶背离60、超买50、放量滞涨45）。
- 叠加分：每多触发一个信号 +5（封顶 +15）。
- 卖飞防御减分：每满足一条 −10（封顶降一级）。

### 3.3 卖出紧急度分级

| 分数 | 图标 | 执行时限 |
|---|---|---|
| 80–100 | 🔴 | 开盘市价卖出 |
| 60–79 | 🟠 | 今日内挂单卖出 |
| 40–59 | 🟡 | 3日内处理 |
| 20–39 | 🟢 | 设置预警跟踪 |
| 0–19 | ✅ | 坚定持有 |

### 3.4 卖飞防御机制（锁定为 AND）

同时满足以下三条 → 卖出等级自动降一级：
1. 板块 RPS > 90（超级热点）
2. 连续 3 日主力净流入
3. 刚放量突破年线

> 「主力净流入」为估算数据（超大单+大单），降级时标注「仅作参考」。

## 4. 质量筛选器（模块4）

### 4.1 四档评级（买卖权限）

| 评级 | 触发条件 | 策略权限 |
|---|---|---|
| ⭐卓越 | ROE(TTM)>15% 且 扣非净利同比>10% | 全策略开放 |
| ✅合格 | 非ST 且 盈利 且 增速≥−10% | 全策略开放 |
| ⚠️预警 | 增速<−10% 或 季报亏损 | 仅持有，不做T，不加仓 |
| 🚫黑名单 | ST/*ST 或 连续亏损 | 永久过滤（除非钻石底） |

**口径（锁定）**：ROE 用 TTM；增速用扣非净利润同比；`min_market_cap=50` 亿元。

**钻石底（锁定）**：破净 且 PE 历史分位 <10% 且 近3年连续盈利 → 可豁免黑名单。

### 4.2 五池分类（正交于评级，锁定）

| 池 | 定义 |
|---|---|
| ⭐核心池 | 评级=卓越，基本面龙头，规模/流动性达标 |
| 🔥热点池 | RPS 动量高 / 板块热度高，短期强势 |
| 💎价值池 | 低估值（低 PE 分位/破净/高股息） |
| 📦观察池 | 评级=合格，暂无突出特征 |
| 🚫黑名单池 | ST/连续亏损，永久过滤 |

评级管「能不能买/持」，池管「按什么风格选」。

## 5. 多策略投票引擎（模块5，Phase 6）

权重矩阵沿用 V5.1（急救/防守/平衡/进攻 × 长线价值/双均线/布林带/RPS/网格）。每策略输出 +1/−1/0，加权求和 → 买入/持有。**职责边界：投票引擎只产出买点信号，卖点一律交模块3。**

## 7. 模拟仓回测引擎（模块7，Phase 9）

**完整建模 A 股规则（锁定）**：T+1、涨跌停无法成交、佣金万2.5、印花税 0.05%（卖出）、过户费、融资利息（约5%/年）、滑点 0.1%。撮合取次日开盘/收盘价。输出胜率/盈亏比/最大回撤/资金曲线，支持不同卖点参数交叉对比。
